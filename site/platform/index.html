What the browser does for Lit

Episode 2: the web platform features underneath Lit, and what each one does for it. About 7 minutes. Episode 1: How lit-html renders.

    The specs and the source

    • Tagged templates: ECMA-262, GetTemplateObject (one frozen template object per literal)
    • The <template> element and its inert template contents
    • Processing instructions in HTML: whatwg/html "Support processing instructions in HTML", the processing instruction target state, and declarative partial updates in Chrome
    • DOM: importNode, TreeWalker and NodeFilter, EventListener handleEvent
    • Custom elements, shadow trees, adoptedStyleSheets
    • The microtask checkpoint in the event loop
    • Lit's source: lit-html.ts, reactive-element.ts, css-tag.ts

    Every fact shown was checked against the specs and captured from Chromium 150 running lit-html 3.3.3 and Lit 3.3.3 (truth/platform.js). Narration: Gemini 3.8 Flash TTS; music: Lyria 3.5. The live version is the same renderer running in your browser. Try it on your own templates in the lit-html explorer.
